# Support

- **Something broke:** open an [issue](https://github.com/konfigure8/chrona-scheduler/issues/new/choose) with the version from the Solutions page, the table and view, and what you saw. Screenshots help.
- **A question or an idea:** start a [discussion](https://github.com/konfigure8/chrona-scheduler/discussions).
- **Anything private,** such as an environment you would rather not name in public: support@chrona365.com.

Answers first come from the [documentation](docs/README.md): the install guide, the bindings, where things are set up, and the questions page.
